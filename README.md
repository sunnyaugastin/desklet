# Desklet

Desklet lets you run HTML projects as native desktop apps on Windows.

## Download
Go to the **Releases** page and download:
- Desklet Setup (recommended)
- Desklet Portable (no install)

## Features
- Run HTML as desktop apps
- Desktop & Start Menu shortcuts
- Per-app icons
- Premium dark UI

## Development
```bash
npm install
npm start
